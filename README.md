# Cache Hit

A colourful 100-level memory card game for the browser. Flip cards, remember where they are, and score a hit. Built with plain HTML, CSS and JavaScript.

## Features

- 100 levels, from 4 pairs up to 18 pairs
- Trophy and confetti when you finish level 100
- Progress is saved, so refreshing keeps you on your current level
- Move limit on every level
- Cards shuffle after wrong guesses in later levels
- 1 to 3 stars for each level
- Title screen with settings for sound effects, music and volume
- Smooth card animations
- Works on desktop and mobile

## How to play

1. Press Play.
2. Memorize the cards while they are shown.
3. Flip two cards at a time and find all the pairs before your moves run out.
4. Clear the level to move on. Reach level 100 to win the trophy.

## Run it

Open `index.html` in any browser. No install needed.

## Files

- `index.html`: page structure
- `style.css`: colours and animations
- `script.js`: game logic, saving and sound
